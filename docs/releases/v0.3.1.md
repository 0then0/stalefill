# StaleFill v0.3.1

This patch release fixes proxy cleanup diagnostics and improves external
validation, failure evidence and packaged documentation.

An upstream connection attempt canceled during cleanup no longer adds a false
`upstream connection failed` event to a completed trace. Genuine connection
failures still produce infrastructure diagnostics. A regression test covers
both cases.

Client compatibility validation can retain every CLI report, configuration,
stderr and fixture log with `--artifact-dir`. Trace mismatch errors show both
event lists, and CI uploads reports even when validation fails. The pinned
gocache positive control checks three complete `FAIL SF001` schedules against
disposable Redis. Artifact uploads use Node.js 24.

Archives include the [gocache upstream regression study](../cases/gocache-upstream-regression.md),
compact evidence, test sources, experimental patch and reproduction guide.
The patch is a local candidate for upstream review; it is not installed into
the pinned fixture or a released upstream fix. Its consistency limits and
UNRESOLVED StaleFill results are documented in the case study.

Existing CLI commands, version-1 configurations, finding IDs, verdict semantics
and supported publication patterns remain compatible. Archives target Linux
amd64/arm64, macOS amd64/arm64 and Windows amd64, with `SHA256SUMS`. Fixture
programs require a source checkout.
