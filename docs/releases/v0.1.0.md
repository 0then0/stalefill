StaleFill 0.1.0 deterministically tests cache-aside races by controlling Redis/Valkey command ordering.

The proxy holds a matching old fill before forwarding, allows a newer authoritative write and invalidation to finish, releases the fill, and checks the final cache-backed HTTP observation. Includes stale-fill and negative-cache scenarios, sequential baseline and wiring checks, four explicit outcomes, secret-free JSON traces, and vulnerable/protected Go demos.

Validated locally against Redis 7.4.11 and Valkey 8.1.10 with 24 repetitions per broken/fixed positive/negative combination. The fixed demo validates cached generations against an authoritative snapshot; it protects API observations rather than preventing all physical stale writes.

Single-node TCP, RESP2 and non-streaming RESP3 only. Lua, transactions, Functions, Cluster, Sentinel, TLS and asynchronous push modes are outside scenario support. See README for pipeline and fixture isolation requirements. Integration testing only; local defaults and explicit remote opt-in.

Archives contain the CLI, README, configuration examples, engineering/research reports, traces and Apache-2.0 license. Verify downloads with SHA256SUMS. Replay and JUnit are future milestones.
